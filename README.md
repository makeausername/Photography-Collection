# 中文摄影作品集

可独立部署的中文摄影作品集，包含照片画廊、360° 全景查看和中文管理后台。

## 功能

- 普通照片展示、分类筛选、全屏查看。
- 360° 球形全景的拖动、缩放、复位和全屏查看。
- 中文后台上传照片，编辑标题、分类、地点、时间和描述。
- 管理作品顺序、删除作品，修改网站名称、个人介绍和联系方式。
- 图片、全景播放器和页面资源均由本站提供，无需外部图床或在线全景服务。

## 本地启动

需要 Node.js 22 或更新的受支持版本。

```sh
npm ci
node scripts/seed-demo.mjs
npm start
```

Windows 也可双击 `启动网站.cmd`。

- 作品集：http://127.0.0.1:4173/
- 中文后台：http://127.0.0.1:4173/admin

首次从本机访问后台时设置自己的管理员密码，没有预设密码。演示素材不属于网站使用者，使用前请在后台替换为自己的作品。

## 后续在本地修改并推送

桌面“光屿摄影作品集”文件夹就是本地 Git 工作目录，远端为本仓库。后续直接在该目录编辑源码，无需再从压缩包复制。

1. 开始前执行 `git status`；没有未提交修改时，可用 `git pull --ff-only` 同步远端。
2. 修改需要的源码，并按改动范围验证；后端功能修改可运行 `npm test`。
3. 执行 `git diff` 检查变更，再用 `git add` 指定实际修改的文件。
4. 执行 `git commit -m "说明本次修改"`，然后 `git push`。

例如只修改画廊布局时：

```sh
git diff
git add public/style.css
git commit -m "调整摄影画廊布局"
git push
```

上传图片、网站设置和管理员密码保存在 `data/`，不进入 Git。`.env` 等本地环境配置和 `node_modules/` 也不提交。`.env.example` 仅提供空配置示例。源码推送到 GitHub 不等于网站已部署或服务器已更新。

## 测试

```sh
npm test
```

测试使用独立临时目录，覆盖登录保护、跨站请求拦截、图片验证、上传、编辑、顺序、重启保留数据和删除，不修改实际作品数据。

## 独立部署与数据备份

见 [使用与部署说明](使用与部署说明.md)。项目附带 Dockerfile 和 compose.yaml。

当前使用单进程本地 JSON 存储，适合个人作品集；未包含多实例写入、客户选片、支付或 RAW 归档。大尺寸全景最高保留 8192 像素宽，尚未提供多级切片功能。
