# 中文摄影作品集

可独立部署的中文摄影作品集，包含照片画廊、360° 全景查看和中文管理后台。

**GitHub 一键部署：** 新服务器无需上传压缩包，安装器会自动克隆本仓库，再配置 HTTPS、续期、SQLite、随机管理员密码和每日备份，并生成私密部署资料。以后执行 `sudo bash /opt/kosmoyonder/deploy.sh update` 自动拉取 main 并部署。首次安装命令见 [一键部署说明](一键部署.md)。

## 功能

- 普通照片展示、分类筛选、全屏查看。
- 360° 球形全景的拖动、缩放、复位和全屏查看。
- 中文后台批量上传照片（逐张进度与失败重试），编辑标题、分类、地点、时间和描述。
- 按标题、地点搜索，按类型／题材／状态筛选，每页 24 幅；多选批量修改题材、地点或发布状态。
- 新作品默认未发布，原有作品保持已发布；公开接口与图片访问均过滤未发布作品，管理员可在后台查看。
- 管理作品顺序、删除作品，修改网站名称、个人介绍和联系方式。
- 图片、全景播放器和页面资源均由本站提供，无需外部图床或在线全景服务。

## 本地启动

需要 Node.js 22.13 或更新的受支持版本。

```sh
npm ci
node scripts/seed-demo.mjs
npm start
```

Windows 也可双击 `启动网站.cmd`。

- 作品集：http://127.0.0.1:4173/
- 中文后台：http://127.0.0.1:4173/admin
- 独立页面：摄影作品 `/works`、360° 全景 `/panoramas`、关于 `/about`。顶部导航会进入对应页面，点击站点名称返回首页；每个地址均支持直接访问和刷新。

首次从本机访问后台时设置自己的管理员密码，没有预设密码。演示素材不属于网站使用者，使用前请在后台替换为自己的作品。

### 多作品本地演示

照片默认展示 6 幅，点击“加载更多作品”每次追加 6 幅；切换分类会重新从该分类的前 6 幅开始。全景默认展示 3 幅，点击“加载更多全景”每次追加 3 幅。其余作品暂不显示，两处展开互不影响。

在 PowerShell 中运行以下命令，可使用独立的 36 幅照片和 6 幅全景演示数据：

```powershell
node scripts/seed-many-demo.mjs
$env:DATA_DIR = Join-Path $PWD 'data\many-works-demo'
$env:PORT = '4174'
npm start
```

访问 http://127.0.0.1:4174/ 。启动前应先停止占用 4174 的旧预览进程。多作品演示使用已有 3 张授权照片和 1 张授权球形全景重复填充，仅用于验证排列、筛选和分批展开；来源与许可保留在作品详情。数据保存在 `data/many-works-demo/`，生成脚本默认不会覆盖已有演示，也不会修改默认的 `data/portfolio.json`。

以下旧版脚本仅适用于尚未迁入 SQLite 的演示；已有 SQLite 时请通过后台管理。若已有旧版多作品演示，可停止预览后执行 `node scripts/seed-many-demo.mjs --add-panoramas`，再重新启动。此选项会备份现有演示数据，并补齐编号 02–06 的全景演示；重复执行不会重复添加。

结束演示后，按 Ctrl+C 停止服务；若要在同一 PowerShell 窗口启动默认作品集，先执行 `Remove-Item Env:DATA_DIR, Env:PORT -ErrorAction SilentlyContinue`，再执行 `npm start`。

## 后续在本地修改并推送

桌面“光屿摄影作品集”文件夹就是本地 Git 工作目录，远端为本仓库。后续直接在该目录编辑源码，无需再从压缩包复制。

1. 开始前执行 `git status`；没有未提交修改时，可用 `git pull --ff-only` 同步远端。
2. 修改需要的源码，并按改动范围验证；后端功能修改可运行 `npm test`。
3. 执行 `git diff` 检查变更，再用 `git add` 指定实际修改的文件。
4. 执行 `git commit -m "说明本次修改"`，然后 `git push`。

例如只修改画廊布局时：

```sh
git diff
git add public/style.css
git commit -m "调整摄影画廊布局"
git push
```

上传图片、网站设置和管理员密码保存在 `data/`，不进入 Git。`.env` 等本地环境配置和 `node_modules/` 也不提交。`.env.example` 仅提供空配置示例。源码推送到 GitHub 不等于网站已部署或服务器已更新。

## 题材与地点

首页使用大图轮播，默认每 7 秒淡入淡出；后台可设置自动播放开关和 3～30 秒停留时间。后台“首页精选 → 首页封面轮播”可独立选择最多 5 张已发布照片、调整顺序，并分别设置电脑和手机的水平/垂直裁切位置，点击“保存封面轮播”生效。初次使用会自动挑选最多 3 张；保存空列表或所选照片全部下架时，使用“网站设置 → 备用封面”，未指定则使用第一张已发布照片。单张时静态展示，无照片时隐藏封面。

前台仅显示角落的暂停/播放按钮，支持键盘左右键和手机滑动；手动切换或键盘聚焦后暂停，可主动恢复。鼠标悬停、封面离开视口、打开看图弹窗和后台标签页时暂缓自动播放；系统减少动态效果时默认不自动播放。第一张直接由服务端输出，显示后预加载下一张，图片仍使用受保护的响应式展示图。裁切仅保存位置，不另外复制图片。桌面封面约占窗口高度的 65%，手机约 48%。

作品使用一个主题材，并独立记录拍摄地点。预设题材依次为「山川湖海、星空银河、朝霞晚霞、云海雾景、人像写真」，普通照片和全景均可选择。地点建议填写“省市 · 景点”，显示在作品标题下，不进入题材筛选。旧作品的自定义分类会继续保留，编辑时可逐步调整；没有作品的题材显示整理中提示。现有演示素材均属于山川湖海，其他题材等待上传真实作品。

尚未迁入 SQLite 的多作品演示可在停止预览后运行 `node scripts/normalize-demo-topics.mjs` 更新旧演示分类，再重启预览。该脚本会备份演示 JSON，只调整标记为演示的旧题材，不修改拍摄地点或默认作品库。

## 页脚与备案

首页底部采用简短介绍和“关于我”入口，完整简介保留在关于页。后台“网站设置”可填写首页简短介绍、邮箱、微信、小红书 HTTPS 主页链接；未填写的联系方式不显示。公开页脚不再提供管理入口，请收藏 `/admin`。

填写本域名已获批的完整 ICP 备案号后，所有公开页面底部中央显示该编号，链接至 `https://beian.miit.gov.cn/`。公安备案号为独立选填项，填写后显示官方图标，并按其中的 14 位数字链接 `https://beian.mps.gov.cn/#/query/webSearch?code=...`。两项独立显示，清空后隐藏；编号与链接在服务器直接输出，不依赖浏览器脚本加载。格式校验不代表已核验备案状态，请以主管部门批准结果为准。

依据：[工信部《非经营性互联网信息服务备案管理办法》第十三条](https://www.miit.gov.cn/gyhxxhb/jgsj/cyzcyfgs/bmgz/xxtxl/art/2024/art_84a0cfa0ebd049bbbe751dca9a008e56.html)，以及[公安备案展示操作说明](https://help.aliyun.com/zh/icp-filing/basic-icp-service/quick-start-for-public-security-network-filing-for-personal-websites)。`public/beian-police.png` 来自[全国互联网安全管理服务平台下载中心的备案编号图标](https://beian.mps.gov.cn/static/national%20emblem.png)，保持官方原图，仅用于公安备案展示。

## 作品保护

默认开启图片右键/拖拽限制和写入像素的 `© KosmoYonder` 水印，后台「网站设置 → 作品保护」可调整。公开照片长边默认 2400px、缩略图 1200px；全景独立保留最高 8192px 宽度并环绕署名。示例素材使用演示水印并保留来源许可。

无水印处理文件仅管理员可访问，公开页面统一使用 `/media/` 展示图，修改设置后刷新即生效。缓存存于 `data/display-cache/`（使用 DATA_DIR 时在对应数据目录）；停止服务后可清空重建。反向代理不得直接暴露 uploads 或 display-cache，也不要给 /media 配置独立的公开缓存。此功能降低直接盗用便利程度，不能阻止截图、开发者工具提取展示图，或收回已保存的文件。

## 微信与小红书分享

作品大图右上角和独立作品页提供「分享作品」。微信面板提供二维码、作品链接和朋友圈卡片；小红书面板提供竖版卡片及可复制的配文，用户自行在小红书发布。不提供微博入口，不自动发布内容；尚未接入微信 JS-SDK 或小红书发布 SDK。

每幅已发布作品都有 `/work/:id` 独立页面，服务端直接输出标题、描述、canonical 和 Open Graph 分享图片信息。横版预览图 1200×630，竖版分享卡片 1080×1440，包含摄影师署名、作品名、地点；竖版带作品二维码。图片保留原比例，分享卡片始终使用带水印的展示图，独立于前台水印开关。示例素材明确标为演示，并保留作者信息。保存分享卡片不会开放无水印图片下载。

本地预览的 127.0.0.1 链接不能发给其他设备访问，二维码也不能用于手机访问。上线时在环境变量或 Docker 的 .env 中设置 `PUBLIC_BASE_URL=https://你的域名`，重启服务后使用正式地址生成卡片；直接 Linux 部署需安装支持中文的 Noto CJK 字体，Docker 镜像已包含。生产反向代理只应接受配置的正式域名。

微信聊天或朋友圈的链接缩略图由客户端决定，Open Graph 标签不能保证微信使用指定卡片。正式域名上线后需在真实微信内验证；如需精确设置微信分享标题和缩略图，后续配置有相应权限的微信账号和 JS-SDK。小红书当前是“保存卡片 + 复制配文 + 手动发布”；直接唤起发布需另行完成官方 SDK 接入与权限配置。不能把当前功能描述为一键发布成功。

草稿、隐藏和删除作品的独立页、二维码、分享卡片均返回 404，分享资源不使用公开持久缓存；平台或访客此前保存的副本无法收回。

### 分享入口的设备适配

微信页签优先检测浏览器原生分享能力：支持时显示“选择应用分享”，调用系统分享菜单；可用目标由设备决定，不能强制指定微信。取消不提示成功、不自动复制；调用失败时保留复制链接入口。没有系统分享能力时，使用“复制链接到微信”，用户切换到微信粘贴。普通网页不使用仅唤起空白微信的 URL Scheme 来冒充转发。

微信内浏览时，提示使用右上角菜单。从作品列表的弹窗进入分享时，先跳到该作品独立页，再引导转发，以免发出的是作品列表链接。“用手机微信打开”的二维码折叠显示；本地地址不显示二维码，分享图片也不嵌入无法跨设备访问的本地二维码。小红书保留保存图片和复制配文。

访客页只保留操作所需的短提示；接入条件、缓存和平台限制见本文，不堆放在作品分享面板。


### 图片格式与服务器空间

新上传的图片保存为高质量 WebP：普通照片长边最高 2800px、全景最高 8192px 宽；后台缩略图长边 600px。无水印处理文件仍仅供管理员访问，网站不保存相机原片，请自行备份原片。

浏览器支持时，公开图片自动返回 WebP（地址继续使用 `.jpg` 以兼容旧链接，实际格式以 Content-Type 为准）。列表、首页封面和作品页通过 srcset 选择合适尺寸，竖图按实际输出宽度标注。全景进入播放器后再加载完整 2:1 图片。旧浏览器按需返回 JPEG，不再在磁盘上留另一套 JPEG 展示图；微信和小红书分享卡片仍为 JPEG，按需生成、不落盘。

展示图缓存只保存 WebP，总容量上限 512 MiB。写入后按最近使用顺序淘汰；7 天未使用的缓存每 30 分钟清理一次，也在启动后的首次图片请求检查。旧版 JPEG 展示缓存自动移除；改水印产生的旧版本也受同一容量与期限限制。源文件不在清理范围内，相同源文件、相同参数的演示作品共享缓存。图片被设为草稿或删除后，即使缓存仍在，也无法从公开地址访问。

已有作品的源文件保持原样，并自动补齐尺寸信息，无需重新上传即可使用 WebP 展示。不会为了转换格式而覆盖或删除已有 JPEG 源文件；因此旧作品的主要空间变化来自展示缓存，新作品从上传时开始节省存储。分辨率和质量已优先考虑摄影作品，但仍建议用实际星空、渐变天空和云海照片检查效果。


### 精选、系列与连续浏览

- 「首页精选」分别选择最多六幅照片、三个全景，点击上移/下移调整顺序，立即保存。独立于作品库排序；隐藏或删除作品后，前台自动排除该作品，不自动补入新上传作品。
- 完整作品页按六张照片、三个全景从服务器分批读取，可按题材筛选，搜索作品名、拍摄地点和年份。空题材不显示。旧 `/api/portfolio` 保留兼容，新前台使用 `/api/site`、`/api/library` 和单幅作品接口。
- 打开大图后可点击箭头、使用键盘左右键或在照片上左右滑动；连续浏览遵循当前搜索和题材条件。全景保留拖动环顾操作。关闭后保留原列表位置。
- 「旅行系列」填写名称、简短记录、封面及发布状态；通过单幅编辑、上传或批量编辑分配作品。一个作品属于一个系列。空系列和未公开系列不展示；隐藏系列不等于隐藏其中已公开的单幅作品。
- 所有作品卡片都有独立详情链接，服务端输出首批作品链接；网站地图仅包含已发布作品与公开的非空系列。`/robots.txt` 提供地图地址；无效地址返回带导航的 404 页面。正式域名通过 PUBLIC_BASE_URL 设置；不保证搜索引擎一定收录。

### 联系与个人照片

公开联系区使用邮箱、小红书、视觉中国及图虫主页链接。未填写的项目自动隐藏。真实作品的「咨询图片使用」会带上作品名称与链接，邮箱按钮自动填写咨询主题。个人照片在网站设置底部单独上传，以最大长边 1400px 的 WebP 保存，不混入作品库；不保留原图与 EXIF。示例图片保留原作者信息，不作为摄影师本人作品宣传。

### 空间统计、重复图片与备份

「存储与备份」可查看 uploads 图片、缩略图、展示缓存及磁盘剩余空间。上传时对原始上传文件计算 SHA-256；与此前新上传的同类型文件完全相同时提示重复，可跳过或明确选择另存。重新导出、改变文件字节的照片以及旧版未记录摘要的文件不做视觉相似性判断。

点击「下载备份」导出 `.tar.gz`，包含 SQLite、通用 JSON、全部作品图片（含 OSS 文件）、个人照片和恢复说明；不含管理员密码、云密钥、相机原片或展示缓存。图片暂存后流式压缩，需要接近图片库大小的临时磁盘空间，OSS 下载可能产生流量费用；同一时间只允许一次导出，期间暂停作品修改。系统需要 tar（Docker 已安装）。

恢复前停止网站并备份现有数据，将压缩包解压到全新的 DATA_DIR，设置 STORAGE_PROVIDER=local 后启动。新目录需要重新设置管理员密码；不要覆盖运行中的 SQLite 或混入旧的 -wal/-shm 文件。备份下载完成后保存到服务器之外；这不是定时自动备份。运行中强制终止进程可能留下 DATA_DIR/.exports 临时快照，可在停服且确认没有导出任务后清理该目录。

## SQLite 与 OSS

默认自动迁移旧 JSON 到 SQLite，并使用本地图片存储。OSS、可选 CDN、迁移命令、完整备份恢复及上线验收步骤见 [OSS 与数据库部署](OSS与数据库部署.md)。后台“存储与备份”可以查看模式、检查连接及重试文件清理。云端配置只通过服务器环境变量提供。
